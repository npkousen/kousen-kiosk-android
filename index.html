What This Project Does

Kousen Kiosk Android is not the kids app. It is a native boundary layer that launches a configured web portal, blocks unsafe navigation, and uses Android Device Owner APIs when a tablet is ready to become a dedicated device.

Shell

Full-screen WebView

The app opens a configured HTTPS home URL without tabs, an address bar, external browser fallback, or arbitrary URL input.

Boundary

Allowed origins only

Top-level navigation outside the configured origins is blocked and is not handed to Chrome, Play Store, or Android intents. Allowed origins can include HTTPS origins and explicit private/local HTTP origins.

Lockdown

Device Owner plus Lock Task

Once provisioned, Android can hide Home, Overview, notifications, Quick Settings, and non-allowlisted apps.

Updates

Keep the native APK boring and stable. Most product iteration should happen on the configured web origin, then the kiosk can reload that origin without rebooting Android.

Web Content

Refresh the site

A refresh button inside kousen.kids is useful, but WebView cache and service workers can still keep old assets alive.

scripts/refresh-web.sh
Hard Refresh

Clear cache only

The default refresh clears WebView HTTP cache and reloads the configured home URL without wiping local site storage.

adb shell am start \
  -n cc.kousen.kiosk/.MainActivity \
  -a cc.kousen.kiosk.action.REFRESH \
  --ez clearCache true \
  --ez clearWebStorage false
Storage Reset

Use carefully

During development, storage can be cleared too. This may remove local progress, IndexedDB, or other saved website state.

scripts/refresh-web.sh true true
APK Updates

Replace the shell

When native code changes, install the new APK over USB. Package replacement relaunches the kiosk path without needing a full tablet reboot.

adb install -t -r app/build/outputs/apk/debug/app-debug.apk
adb shell am start -n cc.kousen.kiosk/.MainActivity
OS Updates

Limit the window

Android does not provide a permanent standard off switch for OS updates. Device Owner policy keeps installs in a 3:00-4:00 AM local maintenance window.

Pending restart: OEM firmware packages can still show a restart-required dialog after an update is already installed. On the TCL 9445X this came from com.tcl.fota.system. The kiosk hides known updater/setup surfaces where Android allows it, but some privileged vendor services may remain active.

Do You Need To Factory Reset?

For your current tablet, probably not as the next immediate experiment. For repeatable dedicated-device setup, yes, factory reset is the clean baseline.

Path Use When Tradeoff
No reset yet The tablet has one user, no Device Owner, no Profile Owner, and no accounts you care about. Fastest way to test dpm set-device-owner. If Android rejects it, reset and repeat cleanly.
Factory reset first You are preparing a final child tablet or documenting a process for future tablets. Most repeatable. You still go through setup prompts, but you start from a known state with no accounts or policies.
Practical rule: test normal app behavior before reset. When you are ready for a real dedicated tablet, factory reset gives you the cleanest Device Owner provisioning path. For this current tablet, you can try provisioning without reset first because dpm list-owners showed no owners.

Normal App Test

This phase verifies the WebView shell before Android lockdown. Do not start Device Owner testing until this list passes.

Authorize ADB

Connect USB, accept the debugging prompt on the tablet, then confirm the device is authorized.

The default profile loads https://kousen.kids.

adb shell am start -n cc.kousen.kiosk/.MainActivity

Test loading, touch, orientation, Back behavior, Pop Party TTS, and normal WebView audio.

Device Owner Lockdown

Device Owner is the Android mode that lets this app become the tablet's Device Policy Controller. Lock Task Mode is what prevents casual exit through Home, Overview, notification shade, and Quick Settings.

Current Tablet Shortcut

Try without reset

If the tablet still has no owners and no blocking accounts, you can try provisioning directly.

adb shell dpm list-owners
adb shell dpm set-device-owner cc.kousen.kiosk/.KioskDeviceAdminReceiver
Repeatable Setup

Reset first

For future tablets, factory reset, complete only the minimal setup needed for USB debugging, authorize ADB, install, then set Device Owner.

adb install -t -r app/build/outputs/apk/debug/app-debug.apk
adb shell dpm set-device-owner cc.kousen.kiosk/.KioskDeviceAdminReceiver

Validate Ownership

The component must match the app package and receiver name.

adb shell dpm list-owners

Launch Into Lock Task

When Device Owner is active, the app allowlists itself, sets itself as the persistent Home activity, starts Lock Task Mode, applies kiosk restrictions, hides known consumer apps, and sets the OS update maintenance window.

After the full policy pass succeeds once in the current process, later resumes skip package inventory and app-hiding work while still checking Lock Task re-entry.

adb shell am start -n cc.kousen.kiosk/.MainActivity
adb shell dumpsys activity | grep -i lock

Test The Boundary

Swipe up, press Home, open Recents, pull notifications, and try Quick Settings. These should be unavailable during Lock Task Mode.

Understand The Back Triangle

On the tested onn tablet in three-button navigation mode, Lock Task Mode removes Home and Overview. Android may still show the Back triangle after an edge swipe. The kiosk handles Back by staying in the WebView or returning to the configured home URL.

Use Kiosk Home Gestures

On gesture-navigation tablets, the kiosk adds WebView-level home gestures. Start at the left edge and make a long swipe right, or start at the bottom edge and make a long swipe up. Either gesture returns to the configured home URL without leaving Lock Task Mode.

Development Escape

Debug builds can normally be removed with dpm remove-active-admin. Factory reset remains the reliable fallback.

adb shell dpm remove-active-admin cc.kousen.kiosk/.KioskDeviceAdminReceiver
adb uninstall cc.kousen.kiosk

Test Reboot

After Device Owner and Lock Task are active, reboot and confirm the tablet returns to the kiosk.

adb reboot
adb wait-for-device
adb shell cmd package resolve-activity --brief -a android.intent.action.MAIN -c android.intent.category.HOME
adb shell dumpsys activity | grep -i cc.kousen.kiosk
adb shell dumpsys activity | grep -i lock

Admin Mode

Admin Mode is a native kiosk feature. It works across Kids, TV, and Command Center profiles because it does not depend on the loaded website.

Touch

Corner hold plus taps

Hold the top-left corner for about 2 seconds until the haptic cue, release, then tap the top-right corner 2 times within 12 seconds.

Remote

D-pad sequence

Use Up Up Down Down Left Right Left Right Select Select within 8 seconds, then enter the Admin PIN.

ADB

Maintenance entry

scripts/open-admin.sh
PIN

Set before real use

The development default is 2468. Change it per device before production use.

scripts/set-admin-pin.sh 1234
Controls

Small by design

Current controls cover homepage/profile editing, brightness, reload, cache clear, site storage clear, and Wi-Fi settings handoff with automatic return to the kiosk.

Display And Admin Access

Kiosk lockdown should keep child-facing controls simple. Brightness, Wi-Fi, and Android Settings are admin concerns.

Wake

No lock screen when possible

As Device Owner, the app requests keyguard disabled. If no PIN, password, or pattern is set, pressing power should wake directly back to the kiosk.

Sleep

Longer display timeout

The Device Owner policy sets a 30-minute screen-off timeout and keeps the tablet awake while plugged into AC, USB, or wireless charging.

Brightness

Admin-level setting

Do not expose brightness to the main kiosk surface. Use Admin Mode or USB during development.

scripts/set-display.sh 180 1800000
Wi-Fi Today

Use Admin Mode

Admin Mode can temporarily relax Wi-Fi restrictions, open Wi-Fi settings, then return to the kiosk and reapply lockdown policy.

Wi-Fi Later

Audit per device

Different tablet and TV vendors may expose different Wi-Fi panels, so each model should be tested before field use.

WebView Troubleshooting

Debug builds expose enough WebView diagnostics to separate network, allowlist, webpage, and renderer problems. Use direct-load tests when a portal card opens a blank page.

Logs

Watch focused WebView output

adb logcat KousenKiosk:D KioskWebViewClient:D KioskWebChrome:D chromium:E cr_media:E '*:S'
KousenTV

Load KousenTV directly

ADB_SERIAL=9878000E3FA8234 scripts/load-url.sh http://192.168.10.10:8000/
Audio

Check KousenTV volume state

If Plex has audio but KousenTV does not, check the web player before changing the Android app. KousenTV stores volume as kousentv.masterVolume; a value of 0 means the video can be unmuted but still silent.

Plex

Load Plex directly

ADB_SERIAL=9878000E3FA8234 scripts/load-url.sh 'http://192.168.10.10:32400/web/index.html#!/'
Interpretation

Read the result

If direct-load works but a homepage card does not, inspect the web link or client-side route. If both fail, check the exact allowlist origin, Wi-Fi, and logcat errors.

Repeatable Tablet Checklist

Use this list when setting up the next onn tablet or another Android dedicated device.

Before Lockdown

Verify app behavior

  • ADB shows the tablet as device.
  • APK installs with adb install -t -r.
  • https://kousen.kids loads.
  • Touch, rotation, Back, TTS, and audio pass.
  • Admin Mode opens by gesture, D-pad sequence, or ADB intent.
  • Web content refresh works with scripts/refresh-web.sh.
Provision

Make it dedicated

  • Start from no owners and no blocking accounts.
  • Set cc.kousen.kiosk/.KioskDeviceAdminReceiver as Device Owner.
  • Launch the app so it starts Lock Task Mode.
  • Confirm system gestures and panels are blocked.
  • Confirm Play Store and other known consumer packages are hidden when present.
After Lockdown

Test appliance behavior

  • Reboot and confirm the kiosk relaunches.
  • Confirm the configured profile persists.
  • Confirm external navigation does not leave WebView.
  • Confirm OS update policy is present in scripts/verify-lockdown.sh.
  • Record any device-specific notes for the next setup.

Kousen Kiosk Android keeps the native app small: Android controls the boundaries, and the website controls the experience.
