Privacy Policy

Kousen Kiosk Android keeps kiosk setup data local to the tablet.

This policy applies to Kousen Kiosk Android, the native Android kiosk shell and static documentation in this repository.

Last updated: August 31, 2026

1. Information The App Handles

The app stores local kiosk configuration such as the profile name, display name, home URL, allowed origins, and offline-cache preference. The default profile opens https://kousen.kids.

2. Local Device Storage

Kiosk configuration is stored on the Android device using app-local storage. WebView may also store normal browser data for the configured site, including cookies, cache, local storage, IndexedDB, Cache Storage, and service-worker data.

3. No Kiosk Backend

Kousen Kiosk Android does not include its own remote provisioning backend, analytics service, account system, or database for collecting tablet setup details.

4. Websites Loaded In The Kiosk

The configured web origin, such as kousen.kids or kousen.cc, controls the product experience inside the WebView. Those websites may handle data according to their own code, hosting environment, and privacy practices.

5. Device Policy Controls

When provisioned as Device Owner, the app can apply Android kiosk controls such as Lock Task Mode and user restrictions. These controls affect device behavior but do not by themselves upload personal information.

6. Text To Speech

The app includes a narrow native TextToSpeech bridge so web content using browser speech synthesis can speak through Android TextToSpeech. The bridge accepts speech text from the trusted WebView page and does not expose filesystem, shell, settings, package management, arbitrary intents, or general native APIs.

7. Debug Builds

Debug builds can enable WebView debugging and logs to support local development. Avoid treating debug APKs as final production builds for unattended tablets.

8. Hosting and Technical Logs

If this documentation is hosted publicly, the hosting provider may process standard request data needed to deliver the static site, such as IP address, browser details, timestamps, requested paths, and CDN or server logs.

9. Children's Privacy

The Android kiosk shell is intended to open approved Kousen web experiences, including child-facing experiences. The shell itself does not create user accounts or intentionally collect personal information from children.

10. Changes to This Policy

This policy may be updated as the kiosk shell gains new setup, administration, or parent-mode capabilities. The revised version will be posted here with a new last-updated date.

11. Contact

If you have questions about this policy, contact:

  • Email: support@kousen.cc
  • Website: https://kousen.cc/
Plain-English summary: the Android app stores kiosk configuration on the tablet, WebView stores normal website data for the configured Kousen site, and there is no separate kiosk backend collecting setup data.
